# Privacy Policy

EZPowers is a local Claude Code and Codex workflow plugin. It does not collect,
transmit, sell, or share personal data on its own.

The plugin contains local instructions, skills, workflow guidance, a
repository documentation registry, and an optional worktree-local wiki. Wiki
SessionEnd capture is disabled by default. When explicitly enabled, the local
runtime stores only a session identifier fingerprint, host/lifecycle metadata,
changed project-relative paths, active plan, and check IDs/statuses. It does
not store transcripts, prompts, responses, tool payloads, command output,
environment variables, credentials, or file contents.

EZPowers makes no network call for documentation lint, wiki storage, or wiki
search. Any data sent to Claude Code, Codex, Anthropic, OpenAI, or another
service is governed by the user's host configuration and the services they
choose to use.

If future EZPowers features add telemetry, network calls, or external integrations, they must be documented here before release.
