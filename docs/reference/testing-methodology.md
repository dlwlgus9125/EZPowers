# Testing Methodology

Maintained by `/design_architecture` and `/sync-docs`. Generated methodology record.

EZPowers is a plugin/library repository. Root verification uses:

- Unit tests: `python -m unittest discover -s tests`
- Harness docs gate: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check-harness-docs.ps1`
- Static eval baseline: `python scripts/run_baseline.py --version local --mode static --splits golden optimization honeypot`
- Harness kit manifest: `python scripts/verify-harness-kit.py`

`ui_verification.required` is false for this repository because there is no UI
runtime surface. Target projects generated by `/setup` must select a UI
verification adapter through `docs/reference/ui-verification-adapter-contract.md`
when they expose UI behavior.
