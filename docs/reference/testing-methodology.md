# Testing Methodology

Maintained by `/design-architecture` and `/sync-docs`. Generated methodology record.

EZPowers is a plugin/library repository. Root verification uses:

- Unit tests: `python -m unittest discover -s tests`
- Structural commit gate: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check-repo.ps1`
- Harness runtime smoke: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/harness-runtime-smoke.ps1`
- Harness kit manifest: `python scripts/verify-harness-kit.py`

`ui_verification.required` is false for this repository because there is no UI
runtime surface. Target projects generated by `/setup` must select a UI
verification adapter through the UI Adapter Evidence section of
`docs/reference/verification-contract.md` when they expose UI behavior.
